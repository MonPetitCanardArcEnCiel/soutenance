\begin{frame}
    \frametitle{The methods in CFD}
    \vspace{-2ex}
    \begin{table}
        \renewcommand{\arraystretch}{1.2}
        \centering
        \small
        \resizebox{\textwidth}{!}{
            \begin{tabular}{m{.1\textwidth}m{.2\textwidth}m{.7\textwidth}}
                Euler&&Inviscid equations. Much cheaper than Navier-Stokes, but inaccurate, especially in turbulent flows.\\
                \pause
                RANS&Reynolds-Averaged Navier Stokes&Navier-Stokes equation are time-averaged before resolution. Subgrid models are used to model turbulence. Cheapest method for Navier-Stokes equations.\\
                \pause
                uRANS&unsteady RANS&Modified RANS method with a phase average instead of a time average. Allow for computation of slow transitory or oscillating phenomenon, but more expensive than RANS.\\
                \pause
                DES&Detached Eddy Simulation&Modified RANS method that switches to LES formulation in zones where the grid is fine enough (with respect the turbulence scale). More accurate than RANS, but necessitate a coarser grid than LES (cheaper).\\
                \pause
                LES&Large Eddy Simulation&Solve low-passed filtered NS equations that ignore smallest scales of turbulence, that are modeled. Much more accurate, especially for complex flows, but very expensive.\\
                \pause
                DNS&Direct Numerical Simulation&Solve the NS equations without any modeling. Prohibitively expensive outside of some simple academic problems.\\
                \pause
                LBM&Lattice-Boltzman Method&Solve a discrete Boltzmann equation instead of NS. Good for flows width different scales, and easily parallelisable. Inefficient for compressible flows. Not widely used for industrial aeronautical applciations.
            \end{tabular}
        }
    \end{table}
\end{frame}

\begin{frame}
    \frametitle{The methods in CEM}
    \begin{table}
        \renewcommand{\arraystretch}{1.5}
        \centering
        \small
        \resizebox{\textwidth}{!}{
            \begin{tabular}{m{.25\textwidth}m{.75\textwidth}}
                Geometric Optics&Ray tracing. Completly ignores any wave behavior. Not differentiable.Very cheap.\\
                Physical Optics&High frequency approximation. Intermediate between GO and full waves methods. Can be extended to take into account diffraction. Cheap.Widely use for industrial scattering problems.\\
                Boundary Element Methods&Full wave method. Use a Green formula to transform a PDE problem in a volume into a variational problem on its boundary. Very efficient for computing unbounded scattering problems in a homogeneous domain. Expensive, but acceleration methods exist. Widely used for industrial scattering problems or antenna computations.\\
                Finite Differences Time Domain&Solve the Maxwell equations using finite differences. Very simple to implement. Unefficient for unbounded problems in a homogeneous domain. Expensive.\\
                Finite Element Method&Solve de Maxwell equations with a finite element method. More efficient for complex or highly heterogeneous domains, but inefficient for unbounded domains.\\
            \end{tabular}
        }
    \end{table}
\end{frame}

\begin{frame}
    \frametitle{Optimization}
    
    \begin{columns}
        \column<1->{.5\textwidth}
            \textbf{Gradient-less algorithms}
            \begin{itemize}[label=\ding{227}]
                \item Require a lot of function evaluations
                \item Computation cost rises quickly with number of parameters.
                \item No gradient
                \item Some algorithms are global
            \end{itemize}
        \column<2->{.5\textwidth}
            \textbf{Gradient-based algorithms}
            \begin{itemize}[label=\ding{227}]
                \item Require less function evaluations
                \item Computation cost less dependant on number of parameters.
                \item Need a way to compute the gradient
                \item Local
            \end{itemize}
    \end{columns}
